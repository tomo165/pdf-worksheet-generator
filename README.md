# PDF Worksheet Generator

A web-based utility designed to generate printable math and learning worksheets as A4 PDF documents.

## Tech Stack
- Frontend: React / Next.js, TypeScript, Tailwind CSS
- PDF Engine: pdf-lib (or jsPDF)
